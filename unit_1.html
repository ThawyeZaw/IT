Topic 1: Hardware and Software

Understanding the components of computing systems and how they work together.

1.1.1 - Features and Functions of Devices

Features vs Functions

A feature is a distinctive characteristic or part of a device, such as its size, weight, or biometric scanner. A function describes how a device operates or its purpose, like making calls or browsing the internet.

Key Features

Portability, Performance, Storage, User Interface, Connectivity, Media Support, Energy Consumption, Expansion Capability, Security Features

1.1.2 - Technologies Used by Devices

Key Technologies:
  • GPS: Small satellite-based navigation increasing power usage but enabling location tracking and mapping.
  • Biometrics: Devices like fingerprint and facial recognition provide strong security.
  • Touchscreen: Combines display and input, saving space and improving usability.
  • Sensors: Include light sensors for brightness adjustment, accelerometers for orientation, motion and temperature sensors for contextual operations.
  • Memory (RAM): Volatile memory affecting multitasking and speed; higher RAM generally improves performance but adds to size.
  • Storage: Non-volatile storage devices like SSDs, HDDs, optical drives; type impacts speed, capacity, and portability.
  • Battery Power: Balances device usage time vs size/weight; innovations include solid-state batteries for better efficiency.
  • Miniaturisation: More transistors on integrated circuits allow smaller devices without losing performance e.g., Raspberry Pi.
  • Processor: CPU speed (GHz) and cores determine processing power and multitasking capabilities.
  • RFID: Tags for tracking items, useful for security and inventory.
  • NFC: Near-field communication for secure short-range data sharing, contactless payments.
  • QR Codes: Barcodes containing data accessible via device cameras for quick information access.
  • Connectivity Hardware: Includes USB ports, HDMI, wireless network interface cards (WNIC), and Bluetooth chips affecting device size and performance.

1.1.3 - Technological Convergence

Technological convergence is when two or more devices combine into one to offer multiple functionalities. This has led to the rise of the Internet of Things (IoT), connecting daily objects over the internet.

Examples:
  • Smart TV: Combines television, internet, apps, and sometimes built-in cameras.
  • Smartphone: Phone, camera, GPS, music player, and computer all integrated.
  • Tablet: Combines a computer with a touchscreen interface.
  • Smart Watch: Functions as a watch, fitness tracker, and phone notification device.

1.1.4 - Embedded Systems

Embedded systems perform dedicated or limited functions, often within other devices. They use microprocessors to process data but have lower performance compared to general computers.

Characteristics:
  • Single or limited functions
  • Dedicated hardware
  • Not easily reprogrammed by users
  • Built into a single chip
  • Contains a microprocessor (small processor variant)

1.1.5 - Firmware

Firmware is essential software embedded in devices to control hardware startup and basic operations.

Includes:
  • BIOS: Basic Input/Output System, initializes hardware during boot-up.
  • Bootloader: Loads the operating system at startup.

Stored in ROM in computers; stored within chip in embedded systems.

1.1.6 - Performance Assessment Factors

Speed

Measured in GHz; faster clock speeds and more cores provide higher processing performance.

Capacity

Storage size; larger capacity supports more data, important for tasks like video editing or large databases.

Portability

Small, lightweight devices are more portable; essential for mobile phones and laptops but less for desktops.

Bandwidth

Network data transmission speed; affects performance where network connectivity matters.

Power Efficiency

Slower energy usage leads to longer battery life, cost savings, and positive environmental impact.

1.1.7 - Binary and Denary Conversion

Denary (decimal) uses base 10 (digits 0-9), binary uses base 2 (digits 0 and 1). Conversion involves using powers of 2 and marking binary digits accordingly.

Denary to Binary Steps:
  • Use powers of 2 (128, 64, 32, 16, 8, 4, 2, 1)
  • Mark '1' if power is included, '0' if not
  • Start with highest power less than or equal to the number
  • Example: 13 converts to 1101 (8 + 4 + 1)

1.1.8 - Data File Sizes

Units of Data:
  • 1 bit = smallest unit of data
  • 1 nibble = 4 bits
  • 1 byte = 8 bits
  • 1 KiB (kibibyte) = 1024 bytes
  • 1 MiB (mebibyte) = 1024 KiB
  • 1 GiB (gibibyte) = 1024 MiB
  • 1 TiB (tebibyte) = 1024 GiB

Important distinction from SI units (e.g., kB=1000 bytes). Use IEC units for accuracy in computing. Example Calculation: A 10 MiB file size implies 10 × 8 × 1024 × 1024 bits for transmission.

1.2.1 - Systems vs Application Software

SYSTEMS SOFTWARE

Software that runs and maintains the computer itself. Examples include operating systems, antivirus, firewalls, drivers, disk defragmentation software.

APPLICATION SOFTWARE

Software designed for end-users to perform specific tasks. Examples include word processors, spreadsheets, databases, photo and video editors, web browsers, and games.

1.2.2 - Operating System Roles

Managing Devices

Operating system uses drivers to manage peripherals and process interrupts efficiently.

Managing Processes

Controls memory allocation, multitasking (switching between tasks), and data transfers between storage and RAM.

Managing Users

Provides GUI, multiple user accounts, handles file operations, and controls user permissions.

Managing Security

Maintains user authentication, data access levels, and runs security utilities like antivirus and firewalls.

1.2.3 - Software Sources

Free Software

Can be studied, modified, and shared; can be free or paid.

Open-Source Software

Source code available for study and modification, usually free; community-driven development.

Proprietary Software

Source code is closed and protected; user cannot modify or redistribute; typically supported by vendor.

Creative Commons

Licenses that specify permissions for software use, such as attribution, non-commercial use, and share-alike conditions.

1.2.4 - Software Licensing

License Types:
  • Single User: For one user on one device.
  • Multiple User: Licensed for a fixed number of devices/users.
  • Institutional: Organization-wide use, based on number of users or devices.
  • Fixed Term: Limited time license, e.g., annual subscriptions.
  • Indefinite (Perpetual): One-time purchase; use indefinitely without renewal fees.
  • Network: Installed on a central server for network-wide access.

1.2.5 - Software Updates

Updates improve software by fixing bugs, adding features, enhancing security, or modifying the user interface.

Update Types:
  • Patch: Quick fixes for urgent bugs or vulnerabilities.
  • Automatic Update: Software updates installed without user intervention.
  • Upgrade: Major new versions with new features that replace old versions.

Compatibility issues can arise if updates do not support older hardware or software environments.

Topic 2: Networks

Understanding how devices connect and communicate with each other.

2.1.1 - Network Models

CLIENT-SERVER

Central server provides services/data to client computers. Server acts as a point of control. Benefits include centralized security, automatic updates, and centralized backups. Drawback: If server fails, clients lose access.

Examples: File servers, web servers, print servers

PEER-TO-PEER (P2P)

All computers (peers) have equal status. Each can act as both client and server, sharing files and resources. No single point of failure. Benefits: Cheap setup, no specialist technicians needed. Drawback: Less secure, each user manages own security.

AD HOC NETWORKS

Temporary network created spontaneously without infrastructure (no router needed). Devices connect directly. Used when sharing resources temporarily, e.g., students sharing project files in a park.

TETHERING

Mobile device shares its internet connection with other devices (turns phone into a hotspot). Useful for internet access while travelling. Can be done via Wi-Fi, Bluetooth, or USB. Drawback: Drains battery and uses mobile data plan.

2.1.2 - Network Protocols

Communication Protocols:
  • Wi-Fi: Wireless LAN using radio waves. 802.11 standard. Uses 2.4 GHz (up to 45m range) or 5 GHz (up to 15m range, faster speeds up to 10 Gbps). Cheap, compatible with many devices.
  • ZigBee®: Low-power wireless for home automation and IoT devices. Uses 2.4 GHz radio waves. Range up to 100m but slower speeds (250 Kbps). Requires ZigBee hub. Used for smart bulbs, thermostats.
  • Bluetooth®: Short-range wireless (10m). Uses 2.4 GHz radio waves. Up to 3 Mbps. Devices connect via "pairing" process. Used for headphones, keyboards, connecting phone to car. Can connect up to 7 devices to host device.
  • Cellular (GSM/3G/4G/5G): Mobile networks using base stations arranged in honeycomb cells. Uses radio waves (phone to base station) and microwaves (between base stations). 2G (0.1 Mbps), 3G (42 Mbps), 4G (150 Mbps), 5G (10 Gbps).
  • Infrared: Line-of-sight wireless using infrared light. Short range, weak signal. Used in remote controls and rarely for peripheral connections (keyboards, mice).
  • Ethernet: Wired connection for LANs. Uses twisted pair, coaxial, or fiber optic cables. Speeds up to 100 Gbps. Cheap, secure, reliable with error detection, easy to install.

2.1.3 - Network Standards

Key Standards and Protocols:
  • TCP/IP: Foundation of internet. TCP ensures reliable data delivery by breaking data into segments, checking for errors, and requesting re-sends. IP handles addressing and routing using IP addresses.
  • VOIP (Voice Over Internet Protocol): Makes voice calls over the internet. Converts voice to digital data, compresses it, and transmits. Used by Skype, FaceTime.
  • SIP (Session Initiation Protocol): Works with VOIP. Establishes, maintains, and terminates communication sessions.
  • OSI Model (7-Layer): Theoretical framework for network communication.
    • 7. Application: User interface, HTTP, FTP
    • 6. Presentation: Data formatting, encoding, encryption, compression
    • 5. Session: Opens, maintains, closes communication sessions
    • 4. Transport: Segments data, controls transmission speed, error checking (TCP)
    • 3. Network: Packets data, routes between networks using routers (IP)
    • 2. Data Link: Frames data, MAC addresses, switches. Two sublayers: Logical Link Control and Media Access Control
    • 1. Physical: Cables, wireless signals, transmits bits
    Memory tip: "All People Seem To Need Data Processing"

2.2.1 - Transmission Media

WIRELESS MEDIA

  • Microwave: Point-to-point, line of sight. High frequency (1-300 GHz). Short wavelength. Used between cell towers.
  • Radio: Omnidirectional, no line of sight needed. Lower frequency (3 kHz - 1 GHz). Travels through walls. Used in wireless LANs.
  • Light (Infrared): Line of sight required. Longer wavelength than visible light. Short range, weak signal.
  • Satellite: Uses radio waves between ground station and satellite. Used in GPS (triangulation with 3+ satellites).

WIRED MEDIA

  • Copper Twisted Pair: Two insulated copper wires twisted together. Electrical signals. Up to 10 Gbps. Cheap, easy to install. Prone to electromagnetic interference. Short distances. Used in phone lines and LANs.
  • Copper Coaxial Cable: Central copper wire with insulation, metal conductor, plastic layer. Radio frequency signals. Up to 10 Mbps. Less interference than twisted pair. Stiff, hard to bend. Used in cable TV and internet.
  • Fibre Optic: Glass/plastic strands transmit light. Up to 1 Gbps. Expensive, fragile. No electromagnetic interference. Long distances. Used for internet and long-distance transmission.
  • Powerline: Uses existing electrical wiring. Up to 2 Gbps. Easy (plug into socket). Prone to interference, depends on wiring condition. Used to extend internet in large buildings.

2.2.2 - Network Metrics

Key Metrics for Performance Measurement:
  • Speed: Rate of data transfer from one device to another (bps or Bps)
  • Bandwidth: Maximum data capacity per second. Shared between devices on network. Higher bandwidth = faster speeds.
  • Throughput: Actual data transmitted vs maximum bandwidth. Often less due to interference and congestion.
  • Scalability: Network's ability to handle larger data volumes. Can bandwidth increase when needed? Important for events like online sales.
  • Latency: Delay in transmission measured as round-trip time (send request, receive response). Lower latency = better performance.
  • Error Rate: Percentage of errors (packet loss, corruption, collisions). High error rate reduces performance due to re-sends.
  • Packet Loss: Percentage of packets sent but not received. Even 1% affects performance.
  • Availability: Percentage of time network is operational. Measured as uptime vs expected uptime.
  • Jitter: Variation in latency due to network congestion. Can cause packet loss.

2.2.3 - Network Components

Key Components and Their Roles:
  • NIC (Network Interface Card): Hardware allowing wired connection. WNIC allows wireless connection. Built into devices.
  • Hub: Basic device connecting multiple devices in LAN. Sends data to ALL connected devices. Inefficient, causes data collisions. Wired connections (ethernet or USB).
  • Switch: Improved hub. Records MAC addresses in table. Sends data only to intended destination device. Reduces traffic and collisions. More efficient than hub.
  • Bridge: Connects two LANs to create larger LAN. Reads MAC addresses to forward data to correct LAN. Used in organizations with multiple building LANs.
  • Gateway: Connects two different networks using different protocols. Translates between protocols (like a translator between languages). Connects LAN to WAN.
  • Router: Forwards data between networks using IP addresses and routing table. Selects best route to destination. Connects LANs to internet.
  • Multi-function Device: Home "router" often combines modem + router + gateway + wireless access point + switch.
  • Modem (Modulator-Demodulator): Converts between analogue and digital signals. Connects to ISP. Built into modern devices.
  • Repeater: Boosts and reconstructs weakened electrical signals. Extends signal range across network.
  • Server: Accepts and responds to requests for data/services. Examples: web server (stores web pages), file server, print server. Often stacked in racks.
  • Wireless Access Point (WAP): Transmits and receives radio wave signals for wireless connections. Devices with WNIC connect to WAP.

2.2.4 - Network Design

When designing networks, consider location of devices, number of users, speed requirements, media type, reliability, cost, security, and maintenance accessibility. Design for current and future needs.

2.2.5 - IP Addressing

IPv4

32-bit addresses in denary. Four sets of digits separated by dots. Example: 128.11.32.40. Addresses running out.

IPv6

128-bit addresses in hexadecimal. Eight sets of digits separated by colons. Example: AB01:EF01:2368:BB30:4324:10DB:0455:BA10. More addresses available.

Static IP

Fixed address that doesn't change. Used for servers that need consistent addresses.

Dynamic IP

Changes when device reconnects. Temporarily assigned by DHCP (Dynamic Host Configuration Protocol). Router or dedicated DHCP server assigns IPs automatically.

MAC Addressing

Physical hardware address assigned by manufacturer to NIC. 12 hexadecimal digits in pairs separated by colons. First 3 pairs = manufacturer ID, last 3 pairs = device serial number. Example: 3C:5A:B4:01:63:D2. Used within LANs.

2.3.1 - Network Security Threats

Threats and Impacts:
  • Unauthorized access (Hacking): Gaining access without permission to steal or corrupt data
  • Malware: Malicious software (viruses, ransomware, spyware, trojans) designed to damage device or data. Often downloaded unknowingly from infected files.
  • Data theft: Sensitive information stolen for fraud, identity theft, or intellectual property theft
  • Denial of Service (DoS): Network overloaded, becomes unavailable
  • Man-in-the-middle attacks: Hacker intercepts communications between two parties

Open Networks: Unsecured networks (no password) are particularly vulnerable. Anyone in range can connect. Common in shopping malls, restaurants.

2.3.2 - Network Security Controls

HARDWARE CONTROLS

Firewall: Physical device between computer and network. Examines incoming/outgoing traffic against criteria (blacklist/whitelist of IP addresses). Accepts or blocks traffic. Protects from hackers and malware before reaching computer.

SOFTWARE CONTROLS

  • Software Firewall: Installed on computer. Examines traffic and dismisses malicious data after it enters.
  • Security Settings: Configure privacy (who sees your data), enable two-factor authentication
  • Anti-malware: Scans device for malware (viruses, spyware). Deletes or quarantines threats. Can scan files before download. Must update regularly for new malware.
  • Access Rights: Attached to username. Limits what data users can see/edit. Prevents accidental deletion and limits hacker access.

AUTHENTICATION TYPES

  • Passwords: Character-based. Strong passwords are long, complex (letters, numbers, symbols)
  • Two-Factor (2FA): Password + second verification (code sent to phone/app). Harder to hack.
  • Biometrics: Biological data as password (fingerprint, iris, facial recognition, voice). Very difficult to fake.

ENCRYPTION

Scrambles data to make it meaningless without key. Symmetric encryption uses same key to encrypt/decrypt. Asymmetric uses different keys. Example: Move each letter 3 places forward (ICT is awesome → LFW lv dzhvrph). Doesn't prevent theft but makes stolen data useless.

PHYSICAL CONTROLS

Physical security measures: Locks on doors, alarm systems, keycard entry, CCTV cameras. Acts as deterrent against device theft and unauthorized physical access. Common in workplaces.

Topic 3: The Online Environment

Understanding how the internet works and its impact on society.

3.1.1 - Internet Structure

The internet is a vast global network of interconnected computers and other devices using the TCP/IP protocol suite for communication.

Structure:
  • Each device connected to the internet is identified by a unique IP address.
  • The Domain Name System (DNS) translates human-readable domain names (like www.google.com) into IP addresses (e.g., 172.217.161.46) that computers use to communicate.
  • DNS is hierarchical with distributed servers to handle billions of domain names efficiently.

3.1.2 - World Wide Web

The World Wide Web is a service layered on top of the internet, consisting of interconnected webpages and resources accessed via HTTP or HTTPS protocols.

Potential and Impact:
  • Enables global sharing of information.
  • Supports e-commerce — buying and selling goods online.
  • Facilitates social connectivity via social media platforms and forums.
  • Supports remote education and remote work environments.
  • Entertainment through streaming services and online games.

3.1.3 - Static vs Dynamic Web Pages

STATIC WEB PAGES

Static web pages display the same content to every user unless manually updated. They are built using HTML and CSS, are fast to load, easy to cache, and cost-effective to create.

DYNAMIC WEB PAGES

Content on dynamic web pages changes based on user input or other factors. They require server-side processing, generate personalized content (e.g., language, user preferences), and are scalable for large sites.

3.1.4 - Client-Side Scripting

Client-side scripts (commonly JavaScript) run in the user's browser. They enhance interactivity, validate forms, enable animations, and reduce server load.

Advantages:
  • Faster user response since no server communication is needed.
  • Works offline after initial load.
  • Users can view and learn from the source code.

3.1.5 - Server-Side Scripting

Server-side scripts (e.g., PHP, Python, Node.js) execute on the web server to generate dynamic content by processing user input, accessing databases, and managing sessions.

Advantages:
  • Code is hidden from the user, increasing security.
  • Enables complex processing and database interaction.
  • Works regardless of client browser capabilities.

3.2.1 - Online Environment Impact

IMPACT ON INDIVIDUALS

Online environments increase productivity through remote collaboration, provide global information access, facilitate social interaction and convenience in shopping, but also expose users to cybersecurity risks.

IMPACT ON ORGANIZATIONS

Organizations benefit from wider customer reach, cost savings from remote work, 24/7 availability, and easy access to data, but face risks from cyber attacks and data breaches.

3.2.2 - Personal Data Protection Online

Protection Methods:
  • Use strong, unique passwords and change them regularly.
  • Enable two-factor authentication (2FA) for additional security.
  • Use updated antivirus and anti-malware software.
  • Employ firewalls to prevent unauthorized access.
  • Use encryption to protect sensitive data.
  • Utilize VPNs to secure internet traffic.
  • Access websites with HTTPS and ensure SSL certificates.
  • Regularly back up data to recover from loss or attacks.

3.2.3 - Digital Footprint

A digital footprint is a trail of all online activities, including browsing, posting, purchases, and data sharing.

ACTIVE FOOTPRINT

Data deliberately shared online such as posts, comments, photos, emails, and purchases.

PASSIVE FOOTPRINT

Data collected without direct user input such as cookies, IP logs, location data, and metadata.

3.3.1 - Online Community Concept

An online community is a virtual space where people with common interests connect for social or professional purposes.

Purposes:
  • Social: Hobbies, entertainment, friendships, support networks, gaming.
  • Professional: Career networking, industry groups, professional development, collaboration, knowledge sharing.

3.3.3 - Monetisation

Monetisation Methods:
  • Targeted Advertising: Ads based on user behavior and interests within the community.
  • Pay-Per-Click Advertising: Revenue generated when users click on ads.
  • Data Selling: Community owners may sell user data to marketers with permission.
  • Subscriptions (Paywalls): Premium content access for paid members.
  • Sponsored Content: Brands pay for promotional content placements.

3.4.1 - Cloud Storage

Cloud storage stores data on remote servers accessible via the internet rather than local devices.

Benefits:
  • Access files from any device and location with internet.
  • Automatic backups handled by cloud providers.
  • Easy file sharing and collaborative editing.
  • Scalable storage where you pay for what you use.
  • Reduces hardware maintenance costs.

3.4.2 - Cloud Computing

Cloud computing allows remote use of software and computing resources hosted on cloud servers.

Types:
  • SaaS (Software as a Service): Online software access e.g., Gmail, Slack.
  • PaaS (Platform as a Service): Platforms for building and deploying applications.
  • IaaS (Infrastructure as a Service): Renting computing infrastructure like servers and storage.

Topic 4: IT Systems

Understanding how IT systems are designed and implemented.

4 - IT System Components

Hardware

Physical devices that are part of the system such as computers, peripheral devices (keyboards, printers), and storage devices.

Example: In an airport check-in system, hardware includes barcode scanners, weighing scales, computers, and printers.

Software

Application and systems software used to operate the hardware and perform tasks.

Example: Operating systems, databases, interfaces for entering information and managing bookings.

Processes

Procedures and workflows defining how data flows through the system and how tasks are performed.

Example: Scanning a boarding pass, weighing luggage, storing customer data.

People

Users, administrators, and developers who interact with or manage the system.

Example: Passengers checking in, airline staff managing data, IT staff maintaining the system.

4.2.1 - Dataflow Diagrams

Dataflow diagrams (DFDs) visually represent how data moves through a system. They show data inputs, processing steps, data stores, and data outputs.

Symbols:
  • Rounded Rectangle: External entity (source or sink of data outside the system)
  • Circle/Bubble: Process that transforms data
  • Rectangle: Data store such as a database or file
  • Arrow: Direction of data flow between elements

Example: For an airport check-in system, data flows from the barcode scanner (external entity), through processes such as scanning and weighing, to data stores with customer and luggage information.

4.3.1 - Flowcharts

Flowcharts visually represent the sequence of steps, decisions, inputs, and outputs within a process or system.

Symbols:
  • Oval: Represents Start or End of process
  • Rectangle: Represents a Process or action step
  • Diamond: Decision point where yes/no or true/false branching occurs
  • Arrow: Flow direction
  • Parallelogram: Input/Output (data entry or display)

Using these symbols correctly makes the flowchart easy to follow and helps visualize complex workflows.

Example: A teacher’s music quiz system flowchart might start with inputting student names and scores, followed by decisions to determine certificate levels and outputs for printing certificates.

4.4 - System Design and Evaluation

When designing an IT system, decomposition helps break down a complex system into manageable sub-systems.

Fit for Purpose means the system meets all its intended requirements as defined in the design brief.

Evaluating the system involves considering the included digital, peripheral, and storage devices, the processes it performs, and if all design goals are met.

Example: A restaurant order system with QR codes for ordering should allow easy menu updates and order transmissions. Evaluation checks if the system is reliable, meets user needs, and is cost-effective.

4.5 - Advantages and Disadvantages of IT Systems

Advantages

  • Automation reduces manual work and human errors
  • Speeds up processing and data access
  • Large data storage and easy access across locations
  • Improves consistency and integration of processes

Disadvantages

  • Initial high cost of setup
  • Staff require training
  • System failures disrupt business
  • Security and privacy risks
  • Dependence on technology may cause vulnerability

Topic 5: Data and Databases

Understanding how data is organized, stored, and managed.

5.1.1 - Data vs Information

DATA

Raw, unprocessed facts such as numbers, text, images, or sounds. Alone, data has no meaning or context.
Example: 25, "John", "blue"

INFORMATION

Processed data given context and meaning, making it useful for decision-making.
Example: "25-year-old John likes blue."

5.1.2 - Structured vs Unstructured Data

STRUCTURED DATA

Data organized in fixed formats (e.g., tables with rows and columns) that follow defined schemas for easy searching and analysis.
Example: Spreadsheets, relational database tables.

UNSTRUCTURED DATA

Data without a predefined format or structure. More challenging to analyze directly.
Example: Emails, social media posts, videos, images.

5.2.1 - Databases

Databases are organized collections of related structured data designed for efficient storage, retrieval, and management. They help maintain data integrity, allow multiple users to access data, and support backup and security.

Benefits of Databases:
  • Efficient data storage
  • Quick data searching and retrieval
  • Maintaining data accuracy
  • Multiple concurrent user access
  • Security controls for sensitive data
  • Backup and recovery options
  • Overall better data organization

5.2.2 - Relational Database Structure

Key Concepts:
  • Table: Data arranged in rows and columns (like a spreadsheet)
  • Record (Row): Represents a single data item or entry
  • Field (Column): Data category or attribute
  • Primary Key: Unique identifier for records to prevent duplicates
  • Foreign Key: Links to a primary key in a different table creating relationships
  • Composite Key: A primary key made from multiple fields combined

5.2.3 - Entity Relationships

ONE-TO-ONE

One record in Table A links to one record in Table B.
Example: One student linked to one emergency contact.

ONE-TO-MANY

One record in Table A links to many records in Table B.
Example: One teacher teaches many students.

MANY-TO-MANY

Many records in Table A link to many records in Table B via a joining table.
Example: Students enroll in many courses; courses have many students.

5.3.1 - SQL Purpose

SQL (Structured Query Language) is the programming language used to manage and query data in relational databases.

Uses of SQL:
  • Retrieve data (SELECT)
  • Add data (INSERT)
  • Modify data (UPDATE)
  • Remove data (DELETE)
  • Create or modify database structure (CREATE TABLE)
  • Combine tables (JOIN)
  • Aggregate functions like COUNT, SUM, AVG

5.3.2 - SQL Commands

Key SQL Commands:
  • SELECT: Retrieve data from a table, e.g., SELECT Name, Age FROM Students;
  • WHERE: Filter results, e.g., SELECT Name FROM Students WHERE Age > 18;
  • INSERT INTO: Add new records, e.g., INSERT INTO Students (Name, Age) VALUES ('John', 25);
  • UPDATE: Modify existing data, e.g., UPDATE Students SET Age = 26 WHERE Name = 'John';
  • DELETE FROM: Remove records, e.g., DELETE FROM Students WHERE Age < 18;
  • JOIN: Combines rows from two or more tables based on a related column.
  • GROUP BY: Groups rows sharing a property, e.g., count per category.
  • ORDER BY: Sorts results in ascending (ASC) or descending (DESC) order.
  • LIKE: Used with wildcards (%) to search patterns in text fields.

Exam Tip: Pay attention to correct spelling and capitalization of field names and tables in SQL commands for the queries to work correctly.

SQL Examples:
  • INNER JOIN:
    SELECT Students.Name, Courses.Title FROM Students INNER JOIN Enrollments ON Students.ID = Enrollments.StudentID INNER JOIN Courses ON Enrollments.CourseID = Courses.ID;
  • GROUP BY:
    SELECT Department, COUNT(*) AS NumEmployees FROM Employees GROUP BY Department;
  • ORDER BY:
    SELECT Name, Age FROM Students ORDER BY Age DESC;
  • LIKE (pattern matching):
    SELECT Name FROM Customers WHERE Name LIKE 'A%';

These queries show how to join tables, group results, sort data, and search for patterns in SQL.

Topic 6: Wider Issues

Understanding the broader impact of technology on society and the environment.

6.1.1 - Environmental Impact

CONSTRUCTION

Building factories to create technology devices often involves clearing natural habitats, disrupting ecosystems, and causing pollution such as noise and harmful gases. Raw materials like precious metals (gold, silver, palladium) are limited and their extraction pollutes soil and water.

USE

Technology consumes significant electricity, especially data centers and network equipment. Many energy sources still rely on fossil fuels, contributing to carbon emissions and global warming.

DISPOSAL

E-waste (discarded electronics) can leak toxic substances into the environment if improperly disposed of in landfills. Recycling can recover precious materials but is not always implemented effectively, creating pollution and health risks.

6.1.2 - Positive Environmental Impact

ENVIRONMENTAL MONITORING

Sensors collect data on air and water quality, temperature, and pollution levels, enabling early detection of environmental problems and promoting conservation efforts.

SMART HOUSES

Automated systems control lighting, heating, and appliances to reduce unnecessary energy use, boosting efficiency and reducing carbon footprint.

SMART CITIES

IT systems optimize traffic flow, manage energy grids efficiently, monitor public transport, and improve waste management to reduce environmental impact and improve urban living.

6.2.1 - Legal Issues

DATA PROTECTION

Laws like GDPR (Europe) and CCPA (California) regulate the collection, storage, and use of personal data, ensuring consent, security, limited access, and data accuracy. Cross-border cloud storage can complicate data protection.

COPYRIGHT

Copyright protects creators' rights over artistic and intellectual works. Unauthorized copying or distribution without permission infringes rights and legal protections like the Berne Convention ensure international recognition.

COMPUTER MISUSE

Laws deter unauthorized access (hacking), data interception, creation/spread of malware, and sabotage of systems. Proving intent is essential in prosecution.

INTELLECTUAL PROPERTY

Patents protect inventions, trademarks protect brand names and logos, and trade secrets protect confidential processes or information vital for competitive advantage.

6.2.2 - Ethical Issues

Key Ethical Concerns:
  • Privacy: Balancing convenience of data tracking (location, online activity) with individuals’ rights to control their information and avoid unauthorized surveillance.
  • Inclusion: Ensuring equitable access to technology across different demographics and accommodating disabled users through accessibility features (screen readers, speech recognition).
  • Civil Liberties: Freedom of expression online versus risks of censorship and harmful content moderation.
  • Access & Accessibility: Addressing the digital divide to prevent exclusion of elderly, remote, or disadvantaged populations from essential digital services.
  • Expression & Association: Protecting rights to express opinions and form online communities while combating extremism and harmful speech.

6.3.1 - Ubiquitous Wireless Access

Wireless internet access is widespread, enabling constant connectivity, supporting IoT devices, and powering smart cities.

Smart Cities Benefits:
  • Connected infrastructure
  • Real-time monitoring and optimization
  • Traffic: Sensors optimize flow, reduce congestion
  • Energy: Smart grid manages distribution
  • Public safety: Real-time emergency response
  • Waste management: Optimize collection routes
  • Air quality: Monitor and alert
