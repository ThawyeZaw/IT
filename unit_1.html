Topics

Topic 1: Hardware and Software

Understanding the components of computing systems and how they work together.

1.1.1 - Features and Functions of Devices

Features vs Functions

A feature is a distinctive characteristic of a device. Functions are ways a device can be used.

Key Features

Portability, Performance, Storage, User Interface, Connectivity, Media Support, Energy Consumption, Expansion Capability, Security Features

1.1.2 - Technologies Used by Devices

Key Technologies:
  • GPS (Global Positioning System)
  • Biometrics (Fingerprint, facial recognition)
  • Touchscreen
  • Sensors (Light, accelerometer, motion, temperature)
  • Memory (RAM)
  • Storage
  • Battery Power
  • Miniaturisation
  • Processor
  • RFID
  • NFC
  • QR Codes
  • Connectivity Hardware

1.1.3 - Technological Convergence

When two or more devices are combined to create a single device or service.

Examples:
  • Smart TV: TV + internet + apps + camera
  • Smartphone: Phone + camera + GPS + music player + computer
  • Tablet: Computer + touchscreen
  • Smart Watch: Watch + fitness tracker + phone notifications

1.1.4 - Embedded Systems

A system with a dedicated, single purpose. Has limited functions.

Characteristics:
  • Single function or limited functions
  • Dedicated hardware
  • Not easily reprogrammed by users
  • Built into a single electronic chip
  • Contains a microprocessor

1.1.5 - Firmware

Basic instructions that allow system to function, including startup and input/output tasks.

Contains:
  • BIOS (Basic Input/Output System): Instructions to boot up computer
  • Bootloader: Loads the operating system when computer turns on

1.1.6 - Performance Assessment Factors

Speed

How quickly device processes instructions (measured in GHz)

Capacity

Amount of storage device can hold

Portability

How easy to carry device around

Bandwidth

Speed at which network transmits data (measured in Gbps or Mbps)

Power Efficiency

How slowly device uses energy

1.1.7 - Binary and Denary Conversion

Humans use DENARY (base 10): 0-9 values. Computers use BINARY (base 2): 0-1 values only.

Denary to Binary:
  • Use powers of 2: 128, 64, 32, 16, 8, 4, 2, 1
  • Mark 1 if value is used, 0 if not used
  • Work from highest to lowest
  • Subtract from remaining value
  • Example: 13 = 1101 (8+4+1)

1.1.8 - Data File Sizes

IEC Units (for storage/transmission):
  • 1 bit = smallest unit
  • 1 nibble = 4 bits
  • 1 byte = 8 bits
  • 1 KiB = 1024 bytes
  • 1 MiB = 1024 KiB
  • 1 GiB = 1024 MiB
  • 1 TiB = 1024 GiB

1.2.1 - Systems vs Application Software

SYSTEMS SOFTWARE

Purpose: Allow computer to run efficiently, maintain computer, perform tasks computer needs

Examples: Operating system, antivirus, firewall, drivers, disk defragmentation, compression software

APPLICATION SOFTWARE

Purpose: Provide services for user, allow user to carry out tasks

Examples: Word processor, spreadsheet, database, photo editor, video editor, web browser, games

1.2.2 - Operating System Roles

Managing Devices

Manages peripheral devices (keyboard, mouse, printer, monitor, scanner)

Managing Processes

Moves data to/from storage and memory (RAM), allocates memory to tasks

Managing Users

Provides graphical user interface (GUI), allows multiple user accounts

Managing Security

Sets username/password, access levels, runs antivirus, firewall

1.2.3 - Software Sources

FREE SOFTWARE

User can study, modify, and share source code. Can be distributed with or without fee.

OPEN-SOURCE SOFTWARE

User can study, modify, and share source code. Usually provided without fee.

PROPRIETARY SOFTWARE

Source code NOT distributed and is protected. User cannot see, study, modify, or redistribute code.

1.2.4 - Software Licensing

License Types:
  • Single User: One user, one computer only
  • Multiple User: Set number of computers
  • Institutional: All computers in organization
  • Fixed Term: Limited time period
  • Indefinite (Perpetual): Use indefinitely
  • Network: Software installed on server

1.2.5 - Software Updates

Reasons for updates: Fix bugs/errors, Add new features, Improve security, Change interface look

Update Types:
  • Patch: Quick-fix for errors or security vulnerabilities
  • Automatic Update: Updates without user consent
  • Upgrade: Whole new version with new features and functionality

Topic 2: Networks

Understanding how devices connect and communicate with each other.

2.1.1 - Network Models

CLIENT-SERVER

Central server provides services/data. Clients request from server. If server fails, clients cannot access services.

PEER-TO-PEER (P2P)

All computers have equal status. Computers can act as both client and server. No single point of failure.

AD HOC NETWORKS

Temporary network created as needed. Devices connect directly without infrastructure.

TETHERING

Mobile device shares its internet connection with other devices.

2.1.2 - Network Protocols

Protocols:
  • Wi-Fi: Wireless local network. 802.11 standard. Radius ~50-100m
  • ZigBee®: Low-power wireless. Used in home automation. Short range
  • Bluetooth®: Short-range wireless (typically 10m). Devices connect directly
  • Cellular (GSM/3G/4G): Mobile networks. Long range via cell towers
  • Infrared: Line-of-sight wireless. Short range. Used in remote controls
  • Ethernet: Wired connection. High speed. Used in LANs and servers

2.1.3 - Network Standards

Key Standards:
  • TCP/IP (Transmission Control Protocol/Internet Protocol): Foundation of internet
  • VOIP (Voice Over Internet Protocol): Converts voice to data packets
  • SIP (Session Initiation Protocol): Establishes, maintains, and terminates communication sessions
  • OSI Model (7-Layer): Application, Presentation, Session, Transport, Network, Data Link, Physical

2.2.1 - Transmission Media

WIRELESS MEDIA

Microwave, Radio, Light, Satellite

WIRED MEDIA

Copper Twisted Pair, Copper Cable, Fibre, Powerline

2.2.2 - Network Metrics

Key Metrics:
  • Speed: How quickly data is transmitted (bps)
  • Bandwidth: Maximum data capacity per second (bps)
  • Throughput: Actual data transmitted vs maximum
  • Scalability: Can network expand to handle more users/devices?
  • Latency: Delay in data transmission (milliseconds)
  • Error Rate: How many data packets are corrupted
  • Packet Loss: Percentage of data packets lost
  • Availability: Percentage of time network is operational
  • Jitter: Variation in latency

2.2.3 - Network Components

Key Components:
  • Switch: Connects devices in LAN
  • Bridge: Connects two LANs
  • Gateway: Connects two different networks
  • Router: Directs traffic between networks using IP addresses
  • Multi-function Device: Combines router + switch + modem functions
  • Modem: Modulates/demodulates. Connects to ISP
  • Repeater: Extends signal range
  • Server: Provides services/data to clients
  • NIC (Network Interface Card): Hardware in device for network connection
  • Wireless Access Point: Allows devices to connect wirelessly to wired network
  • Hub: Basic device connecting network segments

2.2.5 - IP Addressing

IPv4

32-bit addresses. Format: 192.168.1.1. Addresses are running out.

IPv6

128-bit addresses. More addresses available. Format: 2001:0db8:85a3::8a2e:0370:7334

Static IP

Fixed address. Doesn't change. Used for servers.

Dynamic IP

Changes when device reconnects. Assigned temporarily by DHCP.

2.3.1 - Network Security Threats

Threats:
  • Unauthorized access: Without security, anyone can access network
  • Data theft: Sensitive information can be stolen
  • Malware: Viruses, ransomware, spyware can spread
  • Denial of Service: Network overloaded, becomes unavailable
  • Man-in-the-middle attacks: Hacker intercepts communications

2.3.2 - Network Security Controls

HARDWARE CONTROLS

Firewall: Monitors and controls network traffic. Blocks unauthorized access.

SOFTWARE CONTROLS

Security Settings, Anti-malware, User Controls/Access Rights, Authentication, Encryption

PHYSICAL CONTROLS

Restrict physical access to network equipment. Lock server rooms. Secure cables.

Topic 3: The Online Environment

Understanding how the internet works and its impact on society.

3.1.1 - Internet Structure

Global network of interconnected computers using TCP/IP protocol.

Structure:
  • Based on IP addressing: Each device has IP address
  • Based on DNS (Domain Name System): Translates domain names to IP addresses
  • Example: www.google.com → 172.217.161.46

3.1.2 - World Wide Web

Service on top of internet using HTTP/HTTPS protocols. Collection of interconnected documents (web pages) and resources.

Potential:
  • Global information sharing
  • E-commerce: Buying/selling online
  • Social connectivity: Social media, forums
  • Remote work and learning
  • Entertainment and streaming

3.1.3 - Static vs Dynamic Web Pages

STATIC WEB PAGES

Same content displayed to every user. Content doesn't change without manual editing. Created with HTML/CSS.

DYNAMIC WEB PAGES

Content changes based on user input or other factors. Content generated on-demand. Require server processing.

3.1.4 - Client-Side Scripting

Code executed on user's browser (client). Example: JavaScript.

Advantages:
  • Faster response (no server needed)
  • Reduces server load
  • Works offline
  • User can view source code

3.1.5 - Server-Side Scripting

Code executed on web server. Examples: PHP, Python, Node.js.

Advantages:
  • Hidden from user (secure)
  • Server can perform complex operations
  • Access to databases and server resources
  • Works regardless of client capabilities

3.2.1 - Online Environment Impact

IMPACT ON INDIVIDUALS

Increased productivity, Access to information globally, Social connectivity, Shopping convenience, Cybersecurity risks

IMPACT ON ORGANIZATIONS

Reach customers globally, Reduced overhead, 24/7 availability, Data accessibility from anywhere, Cyber attack risks

3.2.2 - Personal Data Protection Online

Protection Methods:
  • Strong passwords: Complex, unique, regularly changed
  • Two-factor authentication: Additional verification method
  • Antivirus/anti-malware: Detect threats
  • Firewalls: Prevent unauthorized access
  • Encryption: Scramble sensitive data
  • VPN: Encrypted tunnel for internet traffic
  • Secure websites: HTTPS, SSL certificates
  • Regular backups: Recover from data loss

3.2.3 - Digital Footprint

All information about you online created by your online activities.

ACTIVE FOOTPRINT

Information you deliberately share: Social media posts, comments, photos, Online purchases, Website registrations, Emails

PASSIVE FOOTPRINT

Information collected without your direct action: Cookies tracking browsing, IP logs, Location data, Metadata in photos/files

3.3.1 - Online Community Concept

Group of people connected via internet with common interests. Don't need to be geographically close.

Purposes:
  • Social: Hobbies and interests, Entertainment, Friendship and socializing, Support networks, Gaming
  • Professional: Networking for career, Industry discussions, Professional development, Project collaboration, Knowledge sharing

3.3.3 - Monetisation

Monetisation Methods:
  • Targeted Advertising: Show ads based on user interests/behavior
  • Pay-Per-Click Advertising: Revenue per ad click
  • Data Selling: Sell user data to marketers
  • Subscriptions (Paywalls): Premium content for paid subscribers
  • Sponsored Content: Brands pay for content placement

3.4.1 - Cloud Storage

Store files on remote servers accessed via internet. Data stored in data centers, not on personal device.

Benefits:
  • Accessibility from anywhere
  • Automatic backup
  • Easy sharing and collaboration
  • Scalability: Pay for what you use
  • No hardware maintenance

3.4.2 - Cloud Computing

Use computing resources (processing power, software) on remote servers.

Types:
  • SaaS (Software as a Service): Use software online (e.g., Gmail, Slack)
  • PaaS (Platform as a Service): Develop applications on cloud platform
  • IaaS (Infrastructure as a Service): Rent computing infrastructure

Topic 4: IT Systems

Understanding how IT systems are designed and implemented.

4.1.1 - IT System Components

Hardware

Physical devices (computers, peripherals, storage)

Software

Applications and systems software

Processes

Procedures and workflows. How data flows through system

People

Users, administrators, developers. User skills and training

4.2.1 - Dataflow Diagrams

Shows how data moves through system. Shows processes that transform data.

Symbols:
  • Rectangle (rounded): External entity (outside system)
  • Circle/bubble: Process (transforms data)
  • Rectangle: Data store (database, file)
  • Arrow: Data flow (direction of data)

4.3.1 - Flowcharts

Visual representation of process or algorithm. Shows sequence of steps.

Symbols:
  • Oval: Start/End
  • Rectangle: Process (action)
  • Diamond: Decision (yes/no branch)
  • Arrow: Flow direction
  • Parallelogram: Input/Output

Topic 5: Data and Databases

Understanding how data is organized, stored, and managed.

5.1.1 - Data vs Information

DATA

Raw facts, numbers, text, images. Has no context or meaning. Example: 25, "John", "blue"

INFORMATION

Data that has been processed and organized. Has context and meaning. Can be used for decision-making. Example: "25-year-old John likes blue"

5.1.2 - Structured vs Unstructured Data

STRUCTURED DATA

Organized in specific format. Follows defined schema. Easy to search and analyze. Example: Spreadsheet, database table

UNSTRUCTURED DATA

No predefined format. Difficult to search and analyze. Variable content. Examples: Emails, documents, images, videos

5.2.1 - Databases

Organized collection of related data. Designed for efficient storage and retrieval.

Why Use Databases:
  • Efficient storage
  • Quick search and retrieval
  • Data integrity (accuracy)
  • Multiple user access
  • Security and access control
  • Backup and recovery
  • Data organization

5.2.2 - Relational Database Structure

Key Concepts:
  • TABLE: Matrix of data (like spreadsheet)
  • RECORD (Row): Single data entry
  • FIELD (Column): Category of data
  • PRIMARY KEY: Unique identifier for each record
  • FOREIGN KEY: Links to primary key in another table
  • COMPOSITE KEY: Primary key made of multiple fields

5.2.3 - Entity Relationships

ONE-TO-ONE

One record in Table A relates to one record in Table B. Example: Person has one Passport.

ONE-TO-MANY

One record in Table A relates to many records in Table B. Example: One Teacher teaches many Students.

MANY-TO-MANY

Many records in Table A relate to many in Table B. Requires junction/linking table. Example: Students enroll in many Courses, Courses have many Students.

5.3.1 - SQL Purpose

Language for managing databases. Works with relational databases.

Purposes:
  • Retrieve data (SELECT)
  • Add data (INSERT)
  • Modify data (UPDATE)
  • Remove data (DELETE)
  • Create table structure (CREATE TABLE)
  • Join tables (JOIN)
  • Aggregate data (COUNT, SUM, AVG)

5.3.2 - SQL Commands

Key Commands:
  • SELECT: Retrieve data. Example: SELECT Name, Age FROM Students;
  • WHERE: Filter by condition. Example: SELECT Name FROM Students WHERE Age > 18;
  • INSERT: Add new record. Example: INSERT INTO Students (Name, Age) VALUES ('John', 25);
  • UPDATE: Modify existing data. Example: UPDATE Students SET Age = 26 WHERE Name = 'John';
  • DELETE: Remove records. Example: DELETE FROM Students WHERE Age < 18;
  • JOIN: Combine data from multiple tables
  • GROUP BY: Group records
  • ORDER BY: Sort results

Topic 6: Wider Issues

Understanding the broader impact of technology on society and the environment.

6.1.1 - Environmental Impact

CONSTRUCTION

Raw materials extraction (mining), Manufacturing energy consumption, Transportation emissions, Packaging waste

USE

Electricity consumption, Data centers energy usage, Network equipment power, Cooling systems energy

DISPOSAL

Electronic waste (e-waste) toxic to environment, Precious metals recovery, Recycling processes, Landfill pollution

6.1.2 - Positive Environmental Impact

ENVIRONMENTAL MONITORING

Sensors collect environmental data (temperature, air quality, water quality). Early warning of problems.

SMART HOUSES

Automated lighting, Thermostats, Appliances. Reduce energy consumption.

SMART CITIES

Traffic optimization, Energy grid optimization, Public transportation monitoring, Waste management optimization.

6.2.1 - Legal Issues

DATA PROTECTION

Regulations: GDPR (Europe), CCPA (California). Personal data collection and storage. Must get consent.

COPYRIGHT

Protects original works (software, music, videos, text). Author has exclusive rights.

COMPUTER MISUSE

Unauthorized access to systems. Hacking is illegal. Creating/spreading malware.

INTELLECTUAL PROPERTY

Patents: Protect inventions. Trademarks: Protect names/logos. Trade secrets: Confidential business information.

6.2.2 - Ethical Issues

Key Ethical Issues:
  • PRIVACY: Right to keep personal information private
  • INCLUSION: Should everyone have access to technology?
  • CIVIL LIBERTIES: Freedom of expression online
  • ACCESS & ACCESSIBILITY: Can people with disabilities use technology?
  • EXPRESSION: Can people say what they want online?
  • ASSOCIATION: Right to online communities

6.3.1 - Ubiquitous Wireless Access

Wireless networks everywhere. Internet accessible from anywhere. IoT devices constantly connected.

Smart Cities Benefits:
  • Connected infrastructure
  • Real-time monitoring and optimization
  • Traffic: Sensors optimize flow, reduce congestion
  • Energy: Smart grid manages distribution
  • Public safety: Real-time emergency response
  • Waste management: Optimize collection routes
  • Air quality: Monitor and alert
