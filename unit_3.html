Topic 12: Manipulating Data

Master data integrity, validation, relational databases, and Big Data concepts.

12.1.1 - What is Data Integrity?

Data integrity refers to how reliable and trustworthy a set of data is. It ensures that data remains accurate, consistent, complete, and free from error throughout its lifecycle.

Why is Data Integrity Important?

  • Ensures business decisions are based on reliable data
  • Prevents errors and inconsistencies
  • Maintains stakeholder and customer trust
  • Enables organizations to comply with legal requirements

Data Governance

Data governance consists of systems, procedures, and policies designed to maintain data integrity.

Components of Data Integrity

Accuracy

Data is correct and free from errors; reflects actual values

Consistency

Data follows set rules and formats

Completeness

All necessary data is included with no missing data points

Reliability

Users can trust the data; it's available when needed

Security

Data is protected from unauthorized access, modification, or deletion

12.1.4-12.1.5 Data Validation

Data validation is the process of checking that data entered into a system follows pre-set rules and meets standards.

The 7 Validation Rules:

Presence Check

Ensures mandatory fields are not left blank

Range Check

Ensures data falls between two accepted values

Lookup Check

Verifies data exists in a predefined reference list

List Check

Restricts data to predefined acceptable entries

Length Check

Ensures data meets minimum/maximum length requirements

Format Check

Ensures data follows a specific pattern

Check Digit

Detects errors in data entry or transmission

12.2 Relational Databases

Data Redundancy

Data redundancy occurs when the same data is unnecessarily stored in multiple locations.

Problems Caused by Data Redundancy

  • Increased storage costs
  • Data inconsistency
  • Maintenance issues
  • Update anomalies

Normalization

Normalization is the process of organizing data to remove redundancy and ensure data integrity.

Three Normal Forms

First Normal Form (1NF)

Remove repeating groups, ensure atomic values

Second Normal Form (2NF)

Remove partial dependencies

Third Normal Form (3NF)

Remove transitive dependencies

12.3 Big Data

Big Data refers to extremely large and complex datasets that are too large to manage with traditional data processing tools.

The 5 V's of Big Data

Volume

Amount of data generated continuously

Velocity

Speed at which data is generated

Variety

Different types and formats of data

Veracity

Quality and reliability of data

Value

Ability to extract meaningful, actionable insights

12.3.4 Data Mining, Warehousing, and Analytics

Data Mining

Process of extracting meaningful information and patterns from large datasets

Data Warehousing

Collection, storage, and management of raw data from multiple sources

Data Analytics

Turning information from data mining into actionable intelligence

Three Types of Data Analytics

Descriptive Analytics

Summarize historical data to understand what happened

Predictive Analytics

Analyze patterns to make predictions about future

Prescriptive Analytics

Suggest actions to optimize outcomes based on predictions

Topic 13: Enabling Technologies

Explore virtualisation, distributed systems, HCI, data security, and encryption.

13.1 Virtualisation

Virtualisation is creating virtual versions of physical resources (computing, storage, networking) using software.

Why Use Virtualisation?

Cost Savings

Multiple virtual machines on one server; reduced hardware needs

Resource Efficiency

Better hardware utilization; dynamic resource allocation

Scalability

Easy to add/remove virtual resources as needed

Disaster Recovery

Quick backup and recovery of entire systems

13.1.2 Two Ways to Achieve Virtualisation

Containerisation

Lightweight, portable packages containing application + all dependencies

Virtual Machines (VMs)

Full OS virtualization where each VM has complete operating system

13.2 Distributed Systems

Distributed system: Computing spread across multiple machines/nodes communicating over networks, working together as single logical system.

Why Needed?

Scalability

Handle more users/data by adding more machines

Redundancy

If one node fails, others continue operating

Resource Sharing

Share databases, computing power across organization

Performance

Solve complex problems faster with parallel processing

13.2.2 Issues with Distributed Systems

Failure

Detecting partial failures is difficult; network partitions create uncertainty

Concurrency

Multiple nodes accessing and modifying same data simultaneously

Replication

Keeping copies of data synchronized across nodes

Performance

Network latency and delays impact responsiveness

13.3 Human Computer Interaction (HCI)

Good HCI improves usability, efficiency, user satisfaction, reduces errors and frustration.

Three Ways HCI is Implemented

Visual

Screen layouts and organization, color schemes, icons

Audio

Sound notifications and alerts, voice feedback

Haptic

Vibrations, tactile feedback, force feedback

13.3.3 Ergonomic Principles

Comfort

Reduce physical strain; proper posture support

Efficiency

Minimize effort required; optimize workflow

Health

Prevent repetitive strain injury, eye strain, fatigue

Accessibility

Design for users with different abilities

13.5 Encryption

13.5.1 Symmetric Encryption

Same key encrypts AND decrypts data. Fast and efficient but key distribution is a problem.

13.5.2 Asymmetric (Public-Key) Encryption

Two keys: public key (encrypts) and private key (decrypts). Solves key distribution problem but slower than symmetric.

13.5.3 Certificate-Based Encryption

Digital certificates verify identity and contain public key. Used for secure websites (SSL/TLS), email, code signing.

Topic 15: Systems Development

Learn project management, waterfall method, agile approach, and system design diagrams.

15.1 PROJECT MANAGEMENT

Success/failure of IT projects depends on project management skills. Proper planning prevents poor performance.

Characteristics of Successful IT Projects

  • Clear, documented objectives and requirements
  • Realistic timelines and deadlines
  • Adequate resources and budget
  • Effective communication and reporting
  • Risk management and contingency planning
  • Quality assurance and testing
  • Stakeholder involvement and satisfaction

15.1.3-15.1.4 SMART TARGETS

Goals must be Specific (clear), Measurable (quantifiable), Achievable (realistic), Relevant (aligned with goals), Time-bound (deadline)

15.1.5-15.1.6 PROJECT MANAGEMENT TOOLS

Gantt Charts

Visual timeline showing tasks, duration, dependencies

Requirements

Functional and non-functional requirements

Critical Path Analysis

Identify longest sequence of dependent tasks

Precedence Tables

Lists tasks and their dependencies

15.2 WATERFALL METHOD

Linear, sequential development where each phase must be completed before next begins.

Six Phases:

Requirements/Analysis

Gather and document ALL requirements

Design

Create system architecture, database design

Implementation

Write code, build system components

Testing/Debugging

Test thoroughly, find and fix bugs

Installation

Deploy to production, user training

Maintenance

Fix issues after launch, updates

Characteristics of Waterfall

Strengths

Comprehensive planning, clear documentation, good for fixed requirements

Weaknesses

Changes difficult, problems found late, inflexible

15.3 AGILE APPROACH

Iterative, incremental development in short cycles (sprints), flexible and adaptive to changes.

Five Phases (repeating cycles):

Requirements

Define features for current iteration

Plan

Break requirements into tasks, estimate effort

Design

Design for current iteration

Develop

Build features (usually 2-4 week sprint)

Release

Demo to stakeholders, gather feedback

Scrum Framework

Common Agile framework with defined roles (Product Owner, Scrum Master, Development Team) and ceremonies (daily standups, sprint review, retrospective).

Characteristics of Agile

Strengths

Flexible, customer feedback incorporated, working software early

Weaknesses

Less formal documentation, requires active customer involvement

16.1 MACHINE LEARNING

Systems that learn patterns from data without explicit programming, improving performance through experience.

Two Types of Machine Learning:

Supervised Learning

Learning from labeled data (correct answers provided)

Unsupervised Learning

Learning from unlabeled data (no correct answers provided)

16.1.2 IMPACT & APPLICATIONS OF MACHINE LEARNING

Natural Language Processing

Understanding and generating human language

Speech Recognition

Converting audio speech to text

Image Recognition

Identifying objects, patterns, faces in images

Pattern Recognition

Detecting patterns and anomalies in data

16.2 VIRTUAL AND AUGMENTED REALITY

16.2.1 VIRTUAL REALITY (VR)

Fully immersive digital environment using headset. User completely immersed (physical world replaced).

Uses:

Entertainment

Games, movies, interactive experiences

Training

Flight simulators, medical training, emergency response

Education

Immersive learning, virtual field trips

Design

Architectural walkthroughs, product visualization

16.2.2 AUGMENTED REALITY (AR)

Digital content overlaid on real world viewed through camera. Real world still visible.

Uses:

Navigation

Real-world directions overlaid on camera

Gaming

Pokémon GO (catch creatures in real locations)

Education

3D models overlaid on textbooks, interactive learning

Maintenance

Repair instructions overlaid on machinery

16.3 INTERNET OF THINGS (IoT)

Network of physical devices with sensors, embedded systems, and network connectivity, collecting and sharing data over internet.

16.3.2 IMPACT OF IoT

On Individuals

Automation, convenience, health monitoring, cost savings

On Organisations

Equipment monitoring, operational efficiency, data collection

On Data

Volume, variety, velocity, privacy concerns

16.3.4 IoT SECURITY ISSUES

Vulnerable Devices

Many IoT devices have weak security

Network Attacks

Intercept data transmission, man-in-the-middle attacks

Data Privacy

Sensitive location and behavioral data collected

Firmware Updates

Devices often not updated regularly
