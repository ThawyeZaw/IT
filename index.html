Topic 7: Understanding HTML

HyperText Markup Language is the foundation of all web pages. Learn document structure, semantic elements, and web components.

7.1.1 - HTML Fundamentals

DOCTYPE & Elements

Every HTML document starts with <!DOCTYPE html> to declare HTML5. Elements are the building blocks made of tags.

Tags & Attributes

Tags tell browsers how to display content. Attributes provide additional info: <img src="file.jpg" alt="text">

Document Language

Declare language with: <html lang="en"> for accessibility and search engines.

7.1.3 - Head Element

What goes in <head>:
  • Metadata (charset, viewport)
  • Page title via <title>
  • Links to stylesheets
  • Scripts and external resources
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Page Title</title> <link rel="stylesheet" href="style.css"> </head> <body> <!-- Content here --> </body> </html>

7.1.4 - Syntax Rules

✓ Lowercase Letters

Use lowercase: <body> not <BODY>

✓ Proper Indentation

Indent nested elements for readability

✓ Double Quotes

Use double quotes for attributes: class="container"

✓ Self-closing Elements

Remove slash: <img> not <img />

7.1.5 - Global Attributes

Key Global Attributes:
  • class - Multiple classes for styling
  • id - Unique identifier (use one per element)
  • style - Inline CSS styles
  • lang - Element language
  • tabindex - Tab navigation order
  • data-* - Custom data attributes
  • hidden - Hide elements
  • accesskey - Keyboard shortcut

7.2.1 - Block vs Inline Elements

Block Elements

Take full width, start new line: <div>, <p>, <h1>-<h6>, <section>, <article>, <header>, <footer>

Inline Elements

Take only needed width, flow in text: <span>, <a>, <strong>, <em>, <img>, <button>

7.2.3 - Key Structural Elements

Text Structure Elements:
  • <article> - Independent content
  • <section> - Thematic grouping
  • <h1>-<h6> - Headings (one H1 per page)
  • <p> - Paragraphs
  • <hr> - Thematic break
  • <strong> - Strong importance
  • <em> - Emphasis (italic)

7.2.4 - Lists

<!-- Unordered List --> <ul> <li>Item 1</li> <li>Item 2</li> </ul> <!-- Ordered List --> <ol start="1" type="a"> <li>First</li> <li>Second</li> </ol> <!-- Definition List --> <dl> <dt>HTML</dt> <dd>HyperText Markup Language</dd> </dl>

7.2.5 - Links

Internal Links

<a href="page.html">Link</a>

External Links

<a href="https://site.com" target="_blank" rel="noopener noreferrer">Link</a>

Email Links

<a href="mailto:user@example.com">Email</a>

Page Anchors

<a href="#section">Jump to Section</a>

7.3.1 - Images

Image Best Practices:
  • Use appropriate format (JPEG for photos, PNG for graphics)
  • Specify width and height to prevent layout shift
  • Maintain aspect ratio: width="400" height="300"
  • Always include descriptive alt text
  • Use CSS to position and style
<img src="image.jpg" alt="Description of image" width="400" height="300">

7.3.2 - Tables

<table> <thead> <tr> <th>Header 1</th> <th>Header 2</th> </tr> </thead> <tbody> <tr> <td>Data 1</td> <td rowspan="2">Spanning 2 rows</td> </tr> </tbody> <tfoot> <tr><td>Footer</td></tr> </tfoot> </table>

7.3.3 - Forms

<form method="POST" action="submit.php"> <fieldset> <legend>Contact Details</legend> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email"> <label for="message">Message:</label> <textarea id="message" name="message" rows="4"></textarea> <select name="category"> <option>Select...</option> <option value="bug">Bug Report</option> </select> <button type="submit">Send</button> </fieldset> </form>

7.3.5 - Audio & Video

<video width="400" height="300" controls> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> Your browser doesn't support HTML5 video. </video> <audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> </audio>

7.3.6 - Inline Frames (iframes)

<iframe src="https://example.com" width="400" height="300" title="External content"></iframe>

Topic 8: Understanding CSS

Cascading Style Sheets control the visual design and layout of web pages. Master selectors, the box model, and responsive design.

8.1.1 - Purpose of CSS

  • Control page layout (positioning, spacing)
  • Ensure consistent design across pages
  • Separate content (HTML) from presentation (CSS)

8.1.2 - Referencing CSS

<!-- Inline Styles --> <p style="color: blue; font-size: 16px;">Text</p> <!-- Internal Stylesheet --> <style> p { color: blue; } </style> <!-- External Stylesheet (Best Practice) --> <link rel="stylesheet" href="css/style.css">

8.1.3 - CSS Rules

selector { property: value; color: blue; font-size: 16px; }

8.1.4 - CSS Selectors

Type Selector

p { } - targets all paragraphs

Class Selector

.highlight { } - targets class="highlight"

ID Selector

#header { } - targets id="header"

Descendant

article p { } - targets p inside article

Child Combinator

ul > li { } - direct children only

Attribute Selector

input[type="email"] { }

8.1.6 - The Box Model

Box Model Layers (outside to inside):
  • Margin - Space outside border
  • Border - Around padding
  • Padding - Space inside border
  • Content - Actual element content
.box { margin: 20px; border: 2px solid black; padding: 15px; width: 300px; /* Total: 300 + 30 (padding) + 4 (border) + 40 (margin) */ }

8.2.1 - Specifying Colors

/* Color Names */ color: blue; /* Hexadecimal */ color: #0066ff; /* RGB */ color: rgb(0, 102, 255); /* Opacity/Alpha */ color: rgba(0, 102, 255, 0.5); /* HSL */ color: hsl(220, 100%, 50%);

8.2.3 - Length Values

Absolute Lengths

px (pixels) - fixed size

Relative Lengths

em (relative to font), rem (relative to root), % (percentage)

8.2.4 - Styling Elements

  • Text layout: text-align, line-height, letter-spacing
  • Fonts: font-family, font-size, font-weight, @import
  • Links: :hover, :visited, :active pseudo-classes
  • Lists: list-style-type, list-style-image
  • Tables: border-collapse, table-layout
  • Forms: input styling, focus states
  • Images: max-width, object-fit

8.3.1 - Positioning Elements

Static (default)

Normal document flow

Relative

Relative to normal position

Absolute

Relative to positioned parent

Fixed

Relative to viewport (stays in place)

8.3.3 - Responsive Design Layouts

Fixed Width

Set width in pixels (less responsive)

Liquid/Fluid

Use percentages to adapt to screen width

CSS Grid

Two-dimensional layout system

Flexbox

One-dimensional flexible layouts

8.3.4 - Responsive Design

/* Mobile-First Approach */ .container { display: grid; grid-template-columns: 1fr; /* Single column on mobile */ } /* Tablet and larger */ @media (min-width: 768px) { .container { grid-template-columns: repeat(2, 1fr); /* 2 columns */ } } /* Desktop and larger */ @media (min-width: 1024px) { .container { grid-template-columns: repeat(3, 1fr); /* 3 columns */ } }

8.4.1 - CSS Transitions

.button { background: blue; transition: background 0.3s ease, transform 0.3s ease; } .button:hover { background: darkblue; transform: scale(1.1); }

CSS Transforms

/* 2D Transforms */ transform: rotate(45deg); transform: scale(1.5); transform: translate(50px, 100px); transform: skew(10deg, 20deg); /* 3D Transforms */ transform: rotateX(45deg); transform: perspective(1000px) rotateY(45deg);

Keyframe Animations

@keyframes slideIn { from { opacity: 0; transform: translateX(-100px); } to { opacity: 1; transform: translateX(0); } } .element { animation: slideIn 0.5s ease-out; }

Topic 9: Understanding JavaScript

JavaScript adds interactivity to web pages. Learn DOM manipulation, events, and programming fundamentals.

9.1.1 - Document Object Model

The DOM is a tree representation of the HTML page that JavaScript can access and modify.

// Selecting Elements document.getElementById('myId'); document.querySelector('.className'); document.querySelectorAll('p'); // Modifying Content element.textContent = "New text"; element.innerHTML = "<strong>Bold</strong>"; // Changing Attributes element.setAttribute('class', 'active'); element.removeAttribute('disabled'); // Adding/Removing Classes element.classList.add('highlight'); element.classList.remove('highlight'); element.classList.toggle('active');

9.2.1 - Regular Expressions

Patterns for matching and validating text.

// Email validation const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/; // Phone number (10 digits) const phoneRegex = /^\d{10}$/; // Uppercase letters const uppercase = /[A-Z]/g; // Numbers const numbers = /\d+/g; // Testing patterns if (emailRegex.test(userEmail)) { console.log("Valid email"); }

9.3.1 - Adding JavaScript

<!-- Inline --> <button onclick="myFunction()">Click</button> <!-- Internal --> <script> function myFunction() { console.log("Clicked!"); } </script> <!-- External (Best Practice) --> <script src="js/script.js"></script>

9.3.2 - Programming Fundamentals

// Variables let name = "John"; const PI = 3.14159; // Data Structures const array = [1, 2, 3, 4]; const object = { name: "John", age: 30 }; // Selection (if/else) if (score >= 70) { console.log("Pass"); } else { console.log("Fail"); } // Repetition (loops) for (let i = 0; i < 5; i++) { console.log(i); } // Iteration array.forEach(item => console.log(item)); // Functions function calculateArea(width, height) { return width * height; } // Arrow Functions const add = (a, b) => a + b;

9.3.3 - JavaScript Events

UI Events

load, unload, resize, scroll

Keyboard Events

keydown, keyup, keypress

Mouse Events

click, dblclick, mouseenter, mouseleave

Form Events

submit, reset, change, focus, blur

// Adding Event Listeners button.addEventListener('click', function(event) { console.log("Button clicked!"); }); // Form Validation form.addEventListener('submit', function(event) { event.preventDefault(); // Stop default submission if (validateForm()) { form.submit(); } }); // Input Event input.addEventListener('input', function(event) { console.log(event.target.value); });

9.3.4 - Interactive Components

  • Slideshows - cycling through images automatically
  • Modal boxes - overlay dialogs
  • Filter/Sort lists - dynamic data manipulation
  • Tabbed content - switching between sections
  • Pop-ups - notification windows

Topic 10: Designing Web Pages

Master design principles, accessibility, and usability for effective web pages.

10.1.1 - Design Process

Wireframes

Low-fidelity layouts showing structure

Mock-ups

High-fidelity visual designs

Style Guide

Color schemes, fonts, spacing

Prototyping

Interactive clickable models

10.1.3 - Design Principles

Visual Hierarchy

Guide users to important content through size, color, position

Flow

Natural path through page (top to bottom, left to right)

Color Theory

Complementary colors, contrast, emotional impact

Balance & Contrast

Symmetrical/asymmetrical layouts with visual interest

10.1.2 - Typography

  • Web-safe fonts: Arial, Verdana, Georgia (default system fonts)
  • Web fonts: Google Fonts, custom @font-face declarations
  • Font pairing: Combine complementary typefaces
  • Readability: Adequate size, line-height, contrast

10.2.1 - WCAG Guidelines

  • Perceivable: Content visible/audible to all users
  • Operable: Keyboard navigable, no seizure risks
  • Understandable: Clear language, predictable navigation
  • Robust: Compatible with assistive technologies

Accessibility Best Practices

  • Alt text on all images
  • Semantic HTML elements
  • Color contrast ratio 4.5:1 for text
  • Keyboard navigation (Tab, Enter, Escape)
  • Screen reader compatible
  • Form labels properly associated
  • Skip navigation links

10.3.1 - Navigation Systems

Vertical Menu

Dropdown

Hierarchical menu structure

Breadcrumb

Shows current location in hierarchy

10.3.2 - Cross-browser Testing

  • Functionality: All features work across browsers
  • Usability: User experience consistent
  • Validation: HTML/CSS passes W3C validators
  • Developer Tools: Browser DevTools for debugging

Topic 11: The Semantic Web

Write meaningful code that describes content for browsers, search engines, and assistive technologies.

11.1.1 - Semantic Markup Importance

  • Describes content meaning (not just appearance)
  • Improves SEO (search engines understand structure)
  • Enhances accessibility (screen readers announce structure)
  • Easier to maintain and understand
  • Benefits mobile devices and assistive tech

11.1.2 - Semantic Structural Elements

<!-- Good semantic structure --> <header> <h1>Site Title</h1> <nav> <ul> <li><a href="#home">Home</a></li> <li><a href="#about">About</a></li> </ul> </nav> </header> <main> <article> <h2>Article Title</h2> <p>Content...</p> </article> <aside> <h3>Related Links</h3> </aside> </main> <footer> <p>© 2024 Company</p> </footer>

Semantic Elements Reference

<header>

Introductory content, navigation

<nav>

Navigation links

<main>

Main content (one per page)

<article>

Self-contained content

<section>

Thematic grouping with heading

<aside>

Sidebar, related content

<footer>

Footer content, meta info

<figure>

Self-contained illustration, diagram, photo

11.1.3 - Non-semantic Grouping

<!-- div for grouping (when no semantic tag applies) --> <div class="container"> <p>Content</p> </div> <!-- span for inline grouping --> <p>This is <span class="highlight">important</span> text.</p>

11.1.5 - Semantic Text Markup

<!-- Importance --> <strong>Important text</strong> <!-- Emphasis --> <em>Emphasized text</em> <!-- Quotations --> <blockquote cite="source">Quote</blockquote> <q>Short quote</q> <!-- Abbreviations --> <abbr title="HyperText Markup Language">HTML</abbr> <!-- Citations --> <cite>Article Title</cite> <!-- Definition --> <dfn>Term being defined</dfn> <!-- Address --> <address>Contact info</address> <!-- Mark --> <mark>Highlighted text</mark>

11.1.6 - Figure and Caption

<figure> <img src="diagram.png" alt="Process flow diagram"> <figcaption>Figure 1: Development Process</figcaption> </figure>

11.1.7 - ARIA Accessibility

  • Roles: Define what element does (role="button")
  • States: Current state (aria-pressed="true")
  • Properties: Characteristics (aria-label, aria-describedby)
  • Live regions: Dynamic content updates (aria-live="polite")
  • Keyboard navigation: tabindex for tab order

11.1.4 - SEO & Semantic Code

  • Search engines use semantic tags to understand structure
  • Proper heading hierarchy improves ranking
  • Schema markup provides rich snippets
  • Semantic code + quality content = better SEO
